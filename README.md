## RepairLab

Код сайта и отдельного Python-приложения находится в [repairlab/](repairlab/).

В публичной версии доступны просмотр, каталог и фильтры; заявки отключены. Для показа Python-бэкенда и SQLite на защите используйте полную локальную версию по [инструкции RepairLab](repairlab/README.md).
